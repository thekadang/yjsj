# 소셜 로그인 구현 가이드

이 문서는 추후 카카오 및 구글 로그인을 구현하기 위해 필요한 절차를 정리한 문서입니다.

## 1. 카카오 로그인 (Kakao Login)

### 1단계: 카카오 개발자 센터 설정
1. [Kakao Developers](https://developers.kakao.com/) 접속 및 로그인.
2. '내 애플리케이션' > '애플리케이션 추가하기'로 새 앱 생성.
3. **앱 키** 확인:
   - `JavaScript 키`: 프론트엔드 SDK 사용 시 필요.
   - `REST API 키`: REST API 방식 사용 시 필요.
4. **플랫폼** 설정:
   - [Web] 플랫폼 등록 -> 사이트 도메인 등록 (예: `http://localhost:5173`, `https://your-domain.com`).
5. **카카오 로그인** 활성화:
   - '카카오 로그인' 메뉴에서 상태를 `ON`으로 변경.
   - **Redirect URI** 설정 (예: `http://localhost:5173/oauth/kakao/callback`).
6. **동의항목** 설정:
   - 닉네임, 프로필 사진, 이메일 등 필요한 정보 설정 (이메일은 검수 필요할 수 있음).

### 2단계: 프론트엔드 구현 (`client`)
1. 카카오 SDK 설치 또는 REST API 방식 선택.
2. 로그인 버튼 클릭 시 카카오 인증 페이지로 리다이렉트 (`https://kauth.kakao.com/oauth/authorize...`).
3. 사용자 동의 후 Redirect URI로 이동하며 `code` (인가 코드) 반환.
4. 프론트엔드에서 이 `code`를 백엔드로 전송.

### 3단계: 백엔드 구현 (`server`)
1. 프론트엔드로부터 받은 `code`를 사용해 카카오 토큰 서버(`https://kauth.kakao.com/oauth/token`)로 요청 -> **Access Token** 발급.
2. 발급받은 Access Token으로 카카오 사용자 정보 API(`https://kapi.kakao.com/v2/user/me`) 호출 -> 사용자 정보(ID, 닉네임 등) 획득.
3. **DB 처리**:
   - 카카오 ID(고유번호)로 기존 회원인지 확인.
   - **신규 회원**: DB에 저장(회원가입 처리) 후 자체 JWT 토큰 발급.
   - **기존 회원**: 바로 자체 JWT 토큰 발급.
4. 클라이언트에게 자체 JWT 토큰 응답.

## 2. 구글 로그인 (Google Login)

### 1단계: Google Cloud Console 설정
1. [Google Cloud Console](https://console.cloud.google.com/) 접속.
2. 새 프로젝트 생성.
3. **API 및 서비스** > **OAuth 동의 화면** 구성:
   - User Type: 외부(External) 선택.
   - 앱 이름, 사용자 지원 이메일 등 입력.
4. **사용자 인증 정보** > **사용자 인증 정보 만들기** > **OAuth 클라이언트 ID** 선택.
   - 애플리케이션 유형: `웹 애플리케이션`.
   - **승인된 자바스크립트 원본**: `http://localhost:5173` 등 프론트엔드 도메인.
   - **승인된 리디렉션 URI**: `http://localhost:5173` (팝업 방식 사용 시 불필요할 수 있으나 설정 권장).
5. 생성된 **클라이언트 ID** 복사.

### 2단계: 프론트엔드 구현 (`client`)
1. `@react-oauth/google` 라이브러리 설치 권장 (또는 Google Identity Services SDK 직접 사용).
   ```bash
   npm install @react-oauth/google
   ```
2. `GoogleOAuthProvider`로 앱 감싸기 (클라이언트 ID 입력).
3. `GoogleLogin` 컴포넌트 사용 또는 커스텀 버튼 구현.
4. 로그인 성공 시 `credential` (JWT 형태의 ID Token) 반환됨.
5. 이 `credential`을 백엔드로 전송.

### 3단계: 백엔드 구현 (`server`)
1. `google-auth-library` 설치.
   ```bash
   npm install google-auth-library
   ```
2. 프론트엔드에서 받은 `credential` (ID Token) 검증.
   ```typescript
   const ticket = await client.verifyIdToken({
       idToken: token,
       audience: CLIENT_ID,
   });
   const payload = ticket.getPayload();
   // payload['sub'] (구글 고유 ID), payload['email'] 등 확인
   ```
3. **DB 처리**:
   - 구글 ID(`sub`)로 기존 회원 확인.
   - **신규/기존** 여부에 따라 회원가입/로그인 처리.
4. 자체 JWT 토큰 발급 및 응답.

## 3. 공통 사항 (DB 스키마 변경 필요)
`users` 테이블에 소셜 로그인 정보를 저장할 컬럼을 추가하거나, 별도의 `social_accounts` 테이블을 만드는 것이 좋습니다.

**방법 A: users 테이블 확장 (간단)**
- `provider`: 'local', 'kakao', 'google'
- `social_id`: 소셜 제공자의 고유 ID (비밀번호는 소셜 로그인 시 null일 수 있음)

**방법 B: social_accounts 테이블 분리 (확장성 좋음)**
- `user_id`: users 테이블 FK
- `provider`: 'kakao', 'google'
- `social_id`: 소셜 고유 ID
