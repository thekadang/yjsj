## 🎯 시스템 개요

### 시스템 아키텍처
```
[클라이언트] ↔ [웹 서버] ↔ [애플리케이션 서버] ↔ [데이터베이스]
                    ↕                ↕
              [CDN/파일저장소]    [외부 API]
                                 - SMS 서비스
                                 - 카카오톡 API
                                 - 결제 PG
```

### 기술 스택
- **Frontend**: React.js, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js, TypeScript
- **Database**: PostgreSQL, Redis (캐시)
- **Storage**: AWS S3 + CloudFront CDN
- **Authentication**: JWT, OAuth 2.0
- **External APIs**: 카카오톡, SMS, PG 결제

## 👤 사용자 관리 시스템

### FS-001: 회원가입 기능

#### 기능 개요
사용자가 이메일 또는 소셜 계정으로 회원가입하는 기능

#### 상세 명세

##### 입력 데이터
- **필수 항목**
  - 이메일 주소 (유효성 검증)
  - 비밀번호 (8자 이상, 영문+숫자+특수문자)
  - 비밀번호 확인
  - 이름 (실명)
  - 휴대폰 번호 (SMS 인증)
- **선택 항목**
  - 생년월일
  - 성별

##### 처리 로직
1. **입력 유효성 검증**
   ```javascript
   // 이메일 형식 검증
   const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
   
   // 비밀번호 강도 검증
   const passwordRegex = /^(?=.*[a-zA-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/;
   
   // 휴대폰 번호 형식 검증
   const phoneRegex = /^010-\d{4}-\d{4}$/;
   ```

2. **중복 검사**
   - 이메일 중복 확인
   - 휴대폰 번호 중복 확인

3. **SMS 인증**
   - 6자리 인증번호 생성
   - SMS 발송 (유효시간 3분)
   - 인증번호 검증

4. **계정 생성**
   - 비밀번호 해싱 (bcrypt, salt rounds: 12)
   - 사용자 정보 DB 저장
   - 이메일 인증 링크 발송

##### 출력 데이터
```json
{
  "success": true,
  "message": "회원가입이 완료되었습니다. 이메일 인증을 완료해주세요.",
  "userId": "user_12345",
  "email": "user@example.com"
}
```

##### UI/UX 명세
- **페이지 구성**: 단일 페이지, 스텝별 진행
- **입력 폼**: 실시간 유효성 검증 표시
- **진행 표시**: 프로그레스 바 (1/3, 2/3, 3/3)
- **에러 처리**: 필드별 에러 메시지 표시
- **성공 처리**: 이메일 인증 안내 모달

##### 예외 처리
- 이메일 중복: "이미 가입된 이메일입니다"
- SMS 전송 실패: "SMS 전송에 실패했습니다. 다시 시도해주세요"
- 인증번호 불일치: "인증번호가 올바르지 않습니다"
- 네트워크 오류: "네트워크 연결을 확인해주세요"

## 📷 영정사진 관리 시스템

### FS-005: 영정사진 업로드 기능

#### 기능 개요
고화질 영정사진을 업로드하고 최적화하여 저장하는 기능

#### 상세 명세

##### 입력 데이터
- **파일 정보**
  - 파일 형식: JPG, PNG
  - 최대 크기: 10MB
  - 권장 해상도: 1200x1600 이상
- **메타데이터**
  - 업로드 일시 (자동)
  - 사용자 ID

##### 처리 로직
1. **파일 유효성 검증**
   ```javascript
   function validateImageFile(file) {
     const allowedTypes = ['image/jpeg', 'image/png'];
     const maxSize = 10 * 1024 * 1024; // 10MB
     
     if (!allowedTypes.includes(file.type)) {
       throw new Error('JPG, PNG 파일만 업로드 가능합니다');
     }
     
     if (file.size > maxSize) {
       throw new Error('파일 크기는 10MB 이하여야 합니다');
     }
   }
   ```

2. **이미지 최적화**
   - 원본 이미지 보존
   - 고화질 버전 생성 (1200x1600)
   - 썸네일 생성 (300x300)
   - WebP 형식으로 추가 변환

3. **파일 저장**
   ```javascript
   const fileStructure = {
     original: `users/${userId}/photos/original_${timestamp}.jpg`,
     highQuality: `users/${userId}/photos/hq_${timestamp}.jpg`,
     thumbnail: `users/${userId}/photos/thumb_${timestamp}.jpg`,
     webp: `users/${userId}/photos/webp_${timestamp}.webp`
   };
   ```

4. **데이터베이스 업데이트**
   - 기존 사진 비활성화 (월 1회 교체 정책)
   - 새 사진 정보 저장

##### 출력 데이터
```json
{
  "success": true,
  "photoId": "photo_12345",
  "urls": {
    "thumbnail": "https://cdn.example.com/thumb_12345.jpg",
    "highQuality": "https://cdn.example.com/hq_12345.jpg"
  },
  "uploadedAt": "2025-09-12T14:30:00Z",
  "nextUpdateAvailable": "2025-10-12T14:30:00Z"
}
```

##### UI/UX 명세
- **드래그 앤 드롭**: 파일 드래그로 업로드
- **미리보기**: 업로드 전 이미지 미리보기
- **진행률**: 업로드 진행률 표시
- **크롭 기능**: 영정사진 비율에 맞게 자르기 (3:4 비율)
- **필터**: 기본 필터 제공 (밝기, 대비, 선명도)

   ```javascript
   function canWriteDiary(userId, date) {
     const todayCount = getTodayDiaryCount(userId, date);
     return todayCount < 2;
   }
   ```

   ```javascript
   function validateDiaryContent(content) {
     if (content.length > 2000) {
       throw new Error('일기는 2,000자를 초과할 수 없습니다');
     }
     
     // 욕설, 부적절한 내용 필터링
     if (containsInappropriateContent(content)) {
       throw new Error('부적절한 내용이 포함되어 있습니다');
     }
   }
   ```

3. **데이터 저장**
   - 작성 시간 자동 기록
   - 수정 불가 플래그 설정
   - 감정 태그 및 날씨 정보 저장

##### 출력 데이터

```json
  "diaryId": "diary_12345",
  "createdAt": "2025-09-12T14:30:00Z",
  "remainingWrites": 1,
  "emotionTag": "감사",
  "weather": "맑음"

```

##### UI/UX 명세
- **에디터**: 리치 텍스트 에디터 (Quill.js)
- **글자 수 카운터**: 실시간 글자 수 표시

  - 브라우저 MediaRecorder API 사용

##### 처리 로직

   ```javascript
   async function requestMicrophonePermission() {
     try {
       const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
       return stream;
     } catch (error) {
       throw new Error('마이크 권한이 필요합니다');
     }
   }
   ```

2. **녹음 시간 관리**
   ```javascript
   function canRecord(userId) {
     const monthlyUsage = getMonthlyAudioUsage(userId);
     const maxMinutes = 30;
     return monthlyUsage < maxMinutes * 60; // 초 단위
   }
   ```

3. **음성 파일 처리**
   - WebM 형식으로 녹음
   - MP3로 변환 (FFmpeg)
   - 음성 품질 최적화 (노이즈 제거)

4. **파일 저장**
   ```javascript
   const audioPath = `users/${userId}/audio/${Date.now()}.mp3`;
   await uploadToS3(audioPath, processedAudio);
   ```

##### 출력 데이터
```json
{
  "success": true,
  "audioId": "audio_12345",
  "duration": 180, // 초
  "remainingMinutes": 27,
  "audioUrl": "https://cdn.example.com/audio_12345.mp3",
  "createdAt": "2025-09-12T14:30:00Z"
}
```

##### UI/UX 명세
- **녹음 버튼**: 큰 원형 녹음 버튼
- **시간 표시**: 현재 녹음 시간 / 남은 시간 표시
- **파형 표시**: 실시간 음성 파형 시각화
- **일시정지**: 녹음 중 일시정지 기능
- **재생**: 녹음 완료 후 바로 재생 가능

### FS-009: 유언장 작성 기능

#### 기능 개요
월 1회 제한으로 유언장을 작성하거나 기존 내용을 교체하는 기능

#### 상세 명세

##### 입력 데이터
- **유언 내용**
  - 최대 5,000자
  - 리치 텍스트 지원
- **공개 설정**
  - 전체 공개 / 가족만 / 특정인만
- **효력 발생 조건** (선택)

##### 처리 로직
1. **작성 권한 확인**
   ```javascript
   function canWriteWill(userId) {
     const lastWill = getLastWill(userId);
     if (!lastWill) return true;
     
     const oneMonthAgo = new Date();
     oneMonthAgo.setMonth(oneMonthAgo.getMonth() - 1);
     
     return lastWill.createdAt < oneMonthAgo;
   }
   ```

2. **법적 고지사항 확인**
   - 법적 효력 없음 동의 필수
   - 개인적 메시지 전달 목적임을 명시

3. **기존 유언 교체**
   ```javascript
   async function replaceWill(userId, newContent) {
     // 기존 유언 아카이브
   ```

## 🗄️ 데이터베이스 설계

### ERD (Entity Relationship Diagram)

```sql
-- 사용자 테이블
CREATE TABLE users (
    id VARCHAR(50) PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255),
    name VARCHAR(100) NOT NULL,
    phone_number VARCHAR(20),
    birth_date DATE,
    gender ENUM('M', 'F'),
    status ENUM('active', 'inactive', 'deceased_verified') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_email (email),
    INDEX idx_phone (phone_number),
    INDEX idx_status (status)
);

-- 영정사진 테이블
CREATE TABLE photos (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,
    original_url VARCHAR(500) NOT NULL,
    high_quality_url VARCHAR(500) NOT NULL,
    thumbnail_url VARCHAR(500) NOT NULL,
    webp_url VARCHAR(500),
    file_size INT,
    dimensions VARCHAR(20), -- "1200x1600"
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_active (user_id, is_active),
    INDEX idx_created (created_at)
);

-- 일기 테이블
CREATE TABLE diaries (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,
    content TEXT NOT NULL,
    emotion_tag VARCHAR(20),
    weather VARCHAR(20),
    type ENUM('text', 'audio') NOT NULL,
    audio_url VARCHAR(500), -- type이 'audio'일 때만
    audio_duration INT, -- 초 단위
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_date (user_id, created_at),
    INDEX idx_type (type)
);

-- 유언장 테이블
CREATE TABLE wills (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,
    content TEXT NOT NULL,
    visibility ENUM('public', 'family', 'specific') DEFAULT 'family',
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_active (user_id, is_active)
);

-- 조회 테이블
CREATE TABLE inquiries (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL, -- 조회 대상자
    requester_name VARCHAR(100) NOT NULL,
    requester_organization VARCHAR(200),
    requester_phone VARCHAR(20) NOT NULL,
    requester_purpose VARCHAR(50),
    status ENUM('pending', 'waiting_response', 'owner_alive', 'presumed_deceased', 'verified_deceased') DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    response_deadline TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_status (user_id, status),
    INDEX idx_created (created_at)
);

-- 결제 테이블
CREATE TABLE payments (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50),
    inquiry_id VARCHAR(50),
    type ENUM('subscription', 'onetime') NOT NULL,
    plan_id VARCHAR(50), -- 구독일 때만
    service_type VARCHAR(20), -- 단건일 때만 (stage1, stage2, combined)
    amount INT NOT NULL,
    status ENUM('pending', 'completed', 'failed', 'refunded') DEFAULT 'pending',
    pg_transaction_id VARCHAR(100),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE SET NULL,
    FOREIGN KEY (inquiry_id) REFERENCES inquiries(id) ON DELETE SET NULL,
    INDEX idx_user_type (user_id, type),
    INDEX idx_status (status)
);

-- 추모 게시판 테이블
CREATE TABLE memorial_posts (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL, -- 고인 ID
    author_name VARCHAR(100) NOT NULL,
    author_relationship VARCHAR(50),
    author_contact VARCHAR(100),
    content TEXT NOT NULL,
    images JSON, -- 이미지 URL 배열
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_created (user_id, created_at)
);

-- 댓글 테이블
CREATE TABLE memorial_comments (
    id VARCHAR(50) PRIMARY KEY,
    post_id VARCHAR(50) NOT NULL,
    author_name VARCHAR(100) NOT NULL,
    author_relationship VARCHAR(50),
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (post_id) REFERENCES memorial_posts(id) ON DELETE CASCADE,
    INDEX idx_post_created (post_id, created_at)
);

-- 구독 테이블
CREATE TABLE subscriptions (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,
    plan_id VARCHAR(50) NOT NULL,
    status ENUM('active', 'paused', 'cancelled', 'expired') DEFAULT 'active',
    billing_key VARCHAR(200), -- PG사 빌링키
    next_billing_date DATE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_status (user_id, status),
    INDEX idx_billing_date (next_billing_date)
);

-- 알림 로그 테이블
CREATE TABLE notification_logs (
    id VARCHAR(50) PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,

    channel ENUM('kakao', 'sms', 'email') NOT NULL,
    content TEXT NOT NULL,
    status ENUM('sent', 'delivered', 'failed') DEFAULT 'sent',
    sent_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_type (user_id, type),
    INDEX idx_sent_at (sent_at)
```

### 인덱스 전략

#### 성능 최적화를 위한 주요 인덱스
1. **복합 인덱스**
   - `(user_id, is_active)`: 활성 사진 조회
   - `(user_id, created_at)`: 시간순 일기 조회
   - `(user_id, status)`: 사용자별 상태 조회

   - `email`: 로그인 시 빠른 조회
   - `phone_number`: SMS 인증 시 조회
   - `created_at`: 시간 기반 정렬
