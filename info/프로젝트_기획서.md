# 영원히 정말 사랑해 진짜로 (영정사진 보관소) 프로젝트 기획서

## 📋 프로젝트 개요

### 서비스명
**영원히 정말 사랑해 진짜로** - 디지털 영정사진 보관소 및 유산 관리 서비스

### 서비스 목적
- 개인의 영정사진과 추억을 안전하게 보관하고 관리
- 사후 가족 및 지인들이 고인의 기록을 열람할 수 있는 플랫폼 제공
- 디지털 시대의 새로운 추모 문화 창조

## 🎯 핵심 기능

### 1. 회원 서비스 (로그인 필요)

#### 1.1 영정사진 관리
- **고화질 영정사진 업로드 및 보관**
- **월 1회 사진 교체 가능** (추가가 아닌 교체 방식)
- 사진 선명도 최적화 기능

#### 1.2 일기장 기능
- **텍스트 일기**: 하루 1-2회 작성 가능
- **음성 일기**: 용량 제한 내에서 음성 녹음
- 작성된 내용은 **수정/삭제 불가** (데이터 무결성 보장)
- 타임스탬프 자동 기록

#### 1.3 유언장 기능
- 월 1회 작성/수정 가능
- 기존 유언 내용 교체 방식
- 법적 효력은 없으나 개인적 메시지 전달 목적

#### 1.4 추모 게시판 기능 (사후 개방)
- **가족/지인 추모글**: 사망 확인 후 누구나 추모글 작성 가능
- **댓글 시스템**: 추모글에 댓글로 추억 공유
- **수정/삭제 금지**: 모든 게시글의 무결성 보장
- **관리자 모니터링**: 부적절한 내용 신고 및 관리

### 2. 비회원 서비스 (간편 업로드)

#### 2.1 기본 정보 입력
- 이름, 주민번호, 가족 정보 입력
- 컴퓨터 사용이 어려운 분들을 위한 간소화된 인터페이스

#### 2.2 제한된 기능
- 영정사진 업로드만 가능
- 일기장, 유언장 등 부가 기능 이용 불가

#### 2.3 회원 전환 시스템
- **비회원 결제 후 회원가입 시 결제 정보 연동**
- 기존 업로드 데이터 자동 연결
- 추가 기능 이용 가능

### 3. 조회 및 열람 시스템

#### 3.1 영정사진 조회 프로세스

##### 3.1.1 비회원 조회 시
1. **조회자 정보 입력 및 인증**
   - 소속(장례식장명, 병원명 등) 필수 입력
   - 이름, 직책/관계 입력
   - 핸드폰 번호 입력 후 **SMS 인증 필수**
   - 조회 목적 선택 (장례준비, 추모, 기타)

2. **1차 조회**: 300×300px 저화질 미리보기 제공

3. **등록자 알림**: 조회 즉시 등록자에게 상세 정보 전송
   - 조회자 소속, 이름, 연락처
   - 조회 시간 및 목적
   - 직접 연락 가능한 조회자 번호 제공

4. **생존 확인 대기**: 3분 내 등록자 응답 대기
   - 등록자가 생존 시: "생존 확인" 메시지 표시 및 서비스 차단
   - **3분 내 응답 없을 시: 사망으로 간주하여 영정사진 이용 허용**

##### 3.1.2 1단계 서비스 (영정사진 이용)
5. **이용 신청**: 상주 등이 "이용하기" 버튼 클릭 → 결제 진행창 이동

6. **이중 알림 발송**
   - 등록자에게: "영정사진 이용 신청됨" 알림 (마지막 기회)
   - 관리자에게: 생존 확인 재검토 요청

7. **1단계 서비스 제공**: **고화질 영정사진 다운로드만** 가능

##### 3.1.3 2단계 서비스 (전체 자료 열람)
8. **사망신고 인증**: 공식 사망신고서 또는 사망진단서 제출

9. **전체 서비스 개방**
   - 일기장 전체 열람
   - 유언장 열람
   - **추모 게시판 접근** (신규 추가)

10. **추모 게시판 이용 규칙**
    - **글 추가**: 가족, 지인 등 누구나 추모글 작성 가능
    - **수정/삭제 금지**: 기존 고인의 글 및 추모글 수정/삭제 불가
    - **댓글 기능**: 추모글에 댓글 작성 가능

#### 3.2 보안 및 프라이버시

##### 3.2.1 조회자 인증 시스템
- **SMS 인증**: 핸드폰 번호 실명 확인
- **소속 검증**: 장례식장, 병원 등 기관 정보 확인
- **조회 기록 보관**: 모든 조회 시도 로그 저장

##### 3.2.2 등록자 보호 시스템
- **실시간 알림**: 조회 즉시 상세 정보 전송
- **직접 연락 지원**: 조회자와 직접 통화 가능
- **관리자 개입**: 의심스러운 조회 시 수동 확인

##### 3.2.3 데이터 보안
- **개인정보 암호화**: 조회자 및 등록자 정보 보호
- **접근 제어**: 사망 확인 전까지 제한적 접근
- **감사 추적**: 모든 접근 기록 추적 가능

## 👥 타겟 사용자

### 주 타겟
- **20-30대 젊은층**: 가장 아름다운 시기의 사진 보관, 불의의 사고 대비
- **40-60대 성인**: 디지털 유산에 관심이 높은 연령층
- **가족 중심적 가치관**: 후손에게 기록을 남기고 싶은 분들
- **중간 소득층 이상**: 월 구독료를 지불할 수 있는 경제력

### 부 타겟
- **20-30대**: 부모님을 위한 서비스 구매
- **시니어층**: 간편 업로드 기능 활용
- **가족 구매층**: 부모님을 위한 서비스 구매

### 마케팅 전략
- **20-30대 대상 캠페인**: "가장 아름다운 순간을 영원히"
  - 영정사진에 대한 거부감 해소
  - 불의의 사고 대비 필요성 인식 제고
  - 젊은 시절의 아름다운 모습 보존 가치 강조

## 🔧 기술 요구사항

### 보안
- **데이터 암호화**: 개인정보 및 콘텐츠 암호화 저장
- **접근 제어**: 다단계 인증 시스템
- **백업 시스템**: 데이터 손실 방지를 위한 다중 백업

### 알림 시스템
- **실시간 알림**: 카카오톡, SMS 연동
- **API 연동**: 카카오톡 비즈니스 API 활용

### 저장소
- **클라우드 스토리지**: 고화질 이미지 및 음성 파일 저장
- **CDN**: 빠른 이미지 로딩을 위한 콘텐츠 전송 네트워크

## 📊 사용자 플로우

### 회원 가입 및 이용
```
회원가입 → 프로필 설정 → 영정사진 업로드 → 구독 선택 → 일기/유언 작성 → 지속적 이용
```

### 조회 및 열람
```
검색 → 미리보기 → 본인 알림 → 생존확인 대기 → 사망확인 → 결제 → 전체 콘텐츠 열람
```

### 비회원 이용
```
개인정보 입력 → 영정사진 업로드 → 완료 (조회만 가능)
```
