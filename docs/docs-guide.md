# 📚 스마트 문서 시스템 가이드

> **claude.md가 지능형 허브로서 자동으로 적절한 문서를 찾아 참조합니다. 사용자는 그냥 자연스럽게 대화하면 됩니다!**

---

## 🎯 핵심 컨셉

### 기존 방식 ❌
```
사용자: "docs/task.md 확인하고 다음 작업 해줘"
사용자: "docs/troubleshooting.md에서 이 에러 찾아줘"
사용자: "docs/structure.md 보고 어디에 만들지 알려줘"
```
→ **사용자가 어떤 문서를 봐야 할지 알아야 함**

### 새로운 방식 ✅
```
사용자: "다음 작업 해줘"
AI: [자동으로 docs/task.md 확인하고 진행]

사용자: "에러가 났어요" + 캡처
AI: [자동으로 docs/troubleshooting.md 검색, 없으면 해결 후 추가]

사용자: "사용자 인증 기능 추가해줘"
AI: [자동으로 docs/structure.md, conventions.md, decisions.md 확인 후 개발]
```
→ **AI가 알아서 필요한 문서를 판단하고 참조**

---

## 🧠 작동 원리

```
사용자 명령
    ↓
claude.md가 의도 파악
    ↓
필요한 문서 자동 선택
    ↓
문서 내용 확인
    ↓
작업 수행
    ↓
관련 문서 자동 업데이트
```

```

"docs/task.md를 확인했습니다. Phase 3-2의 '기능 B: 결제 시스템'을 진행하겠습니다. /src/services/payment_service.py를 생성하고 있습니다..."

   - 해결 후 docs/troubleshooting.md에 추가

```

**AI 응답**:
"docs/troubleshooting.md를 확인했습니다. 이 에러는 데이터베이스 연결 문제입니다. [해결 방법 설명...]"

### 예시 3: 새 기능 개발

**사용자**: "알림 기능 추가해줘"

**AI 내부 동작**:
```
1. "추가" 키워드로 새 기능 요청 감지

6. 개발 진행
7. 완료 후 자동 업데이트:
   - docs/structure.md에 새 파일 추가
   - docs/task.md 체크박스 체크
```

**AI 응답**:
"docs/structure.md와 conventions.md를 참고하여 /src/services/notification_service.py를 생성합니다..."

## 🎯 트리거 키워드

AI가 자동으로 감지하는 키워드들:

### 작업 계속
- "다음 작업", "이어서", "계속", "뭐 해야해", "어디까지 했어"
- → **docs/task.md 자동 참조**

### 에러/문제
- "에러", "오류", "안돼", "실패", "버그", 에러 메시지, 스크린샷
- → **docs/troubleshooting.md 자동 검색**

### 새 기능/코드
- "추가해줘", "만들어줘", "구현해줘", "개발"
- → **docs/task.md, structure.md, conventions.md 자동 참조**

### 코드 찾기
- "어디 있어", "찾아줘", "위치"
- → **docs/structure.md 자동 확인**

### 기술 질문
- "왜", "이유", "~를 쓰는 이유"
- → **docs/decisions.md 자동 확인**

### 수정/개선
- "수정", "고쳐줘", "리팩토링", "개선"
- → **docs/conventions.md 자동 참조**

## 🔄 자동 업데이트

작업 완료 후 AI가 자동으로 업데이트하는 것들:

```
✅ 새 파일 생성 → docs/structure.md 업데이트
✅ 작업 완료 → docs/task.md 체크박스
✅ 에러 해결 → docs/troubleshooting.md 추가
✅ 기술 선택 → docs/decisions.md ADR 추가
✅ API 변경 → docs/api.md 업데이트
```

**사용자가 "업데이트 해줘"라고 요청하지 않아도 자동으로 처리됩니다!**

### 4. 지식 축적

- 기술 결정 이유 자동 기록
